Backups preserve the files. Arkeotype™ preserves the context needed to understand them — four years later, by someone who has never met you.

The durable unit

Three things travel together.

Copy the folder and you carry all three. That is the whole mechanism: keep the story about the content right next to the content.

01 · Object

Preserve the thing

The original stays in its native form — .indd, .psd, camera masters, old Quark files, Excel 1997 files, a database dump. Nothing has to become a .md Markdown file to be kept.

02 · Representation

Preserve a way to perceive it

A transcript beside the video. A PDF beside the MS Publisher layout. A CSV and schema note beside the database. A window into the object for someone who lacks the software that made the original.

03 · Context

Preserve what it means

MANIFEST.md stores: provenance, relationships, decisions, what supersedes what, what to ignore. Structured enough to index (and search), yet loose enough to just write anything into it.

Graceful degradation

Every upper layer is removable.

Indexes regenerate. The interface can disappear and the filesystem remains. AI can disappear and the manifest remains. The Arkeotype app itself can be deleted and the saved collection of project data remains intelligible in any text editor.

AI may help reconstruct meaning. AI must never be required to recover it.

  1. AI & semantic interpretation optional
  2. Index, search, interface regenerable
  3. History & work logs useful
  4. Context — MANIFEST.md file durable
  5. Object + Representation files the ground
Design systems for the next human steward, not the current database vendor. The one sentence Arkeotype is built around

Boundaries

What Arkeotype is not

a backup product a DAM replacement an archival database a note-taking graph a cloud service an LLM wrapper

It assumes humans are messy, institutions lose continuity, applications disappear, and budgets change. Its only job is to keep those ordinary failures from severing the artifact from its meaning.

AI LLM Compatibility

How Arkeotype plays well with others

GEMINI.md AGENTS.md CLAUDE.md MANIFEST.md

<ai-nerds>
Arkeotype names its canonical project-description file MANIFEST.md for what that file contains, rather than for which LLM is expected to consume it (CLAUDE.md, GEMINI.md, etc).

However Arkeotype also adds extra (shim) files as pointers alongside MANIFEST.md, so that each supported AI tool encounters the filename it expects, with each shim pointing to the canonical MANIFEST.md in that project folder.
</ai-nerds>

The application is temporary scaffolding. The archive is not.
